# SmartTalk（智言）输入法

![logo](docs/assets/logo.png)

> 注：本项目目前处于积极开发阶段，欢迎感兴趣的开发者加入！

SmartTalk（智言）输入法是一个计划基于[语燕输入法](https://github.com/gurecn/YuyanIme)开发的智能输入法项目。项目目标是通过集成先进的AI技术，在保持原有输入法轻快、简洁特性的基础上，提供更智能、更个性化的输入体验。

## 💡 项目愿景

升级传统输入法，**从“工具”升级为“教练”**，实现功能融合与创新，让你秒变沟通艺术家！💬✨

- ✅ 情境感知雷达：自动识别职场/恋爱/咨询/商谈等N+场景，智能推荐高情商表达
- ✅ 情绪灭火专家：智能探测对话火药味，危险表达自动拦截，3级话术秒降冲突
- ✅ 语境智能解读：潜台词透视镜，秒破弦外之音，与跨频尬聊说拜拜，趣味话题永不断电
- ✅ 语言预判大师：结合语境智能预判所需表达，秒解词句斟酌难题，助您成为对话达人
- ✅ 人设养成系统：N+预制人设风格，0.1秒变身「霸道总裁/知性博主/学术大牛」
- ✅ 领域专家模式：精准调取法律/医学等专业语料库，商务咨询对答如流
- ✅ 文化语言伴侣：N+语种实时互译，文化典故一键溯源，破除文化屏障解锁文明通识

## 📋 版本规划

计划推出两个版本：

- **基础版**：保持轻量级特性，提供基本的AI智能补全功能
- **专业版**：包含全部AI增强功能，支持更多场景的智能输入

## 🚀 开发计划

### 当前阶段：AI功能开发
计划开发以下AI智能特性，致力于将输入法从"工具"升级为"教练"：

- 🗣️ **场景感知的表达优化**：
  - 基于对话上下文，智能识别感知对话语境（职场、恋爱、闲聊、商谈、咨询、学习……）
  - 结合不同语境的身份、情绪与用语规范，提供智能补全与预测，解放您双手频繁打字负担的同时，提高沟通效率
  - 自动识别并纠正不恰当表达，提供语境相关的高情商替换表达候选建议，助您成力人见人爱的高情感达人

- 🌈 **情绪管理助手**：
  - 结合上下文实时识别感知对话各方情绪
  - 在感知到负面情绪出现激烈用语时，自动给出高情商缓和用语表达候选
  - 帮您有效规避情绪失控情况下，一时口快产生的“伤敌一万，自损八千”局面

- 📚 **贴心智囊助手**：
  - 结合语境，帮您解读商谈中对方的用语意图，智能生成回复建议，助您成为谈判高手
  - 结合语境，生成有趣话题供您参考选用，避免尬聊的同时，展示您的风趣与魅力
  - 结合语境，智能解读输入的图片音频与视频，生成不同风格的摘要描述供您选择，助您成为朋友中的讲故事达人
  - 结合语境，预判并提供可选的对话表达，免去词句斟酌思索时间，助您成为对话达人

- 🎭 **个性形象塑造**：
  - 智能感知用户平时用语习惯，自动生成用户用语风格标签
  - 同时支持用户自定义"人设标签"（如"活泼博主"、"职场精英"）
  - 根据用户用语风格、人设标签，智能调整匹配人设风格的表达用语候选，帮您成为独一无二的您

- 🎓 **智能知识库**：
  - 作为贴心助理，帮您解读对话中的涉及的文化典故、名人故事、诗词歌赋等，让您摆脱记忆和应用切换负担，轻松向对方展示您的博学多才
  - 通过自定义专业领域知识库，支持扩展到特定专业知识领域（如医学、理学、法学等），帮您成为领域专家，助力商业布局

- 🌐 **语言知识与文化助手**：
  - 辅助语言学习，在实际对话语境中提供多语言翻译、解读和地道表达推荐，助您流利地道使用非母语聊天对话
  - 一键解读对话中的生僻字、成语谚语、俗语方言、专业名词等，在平时的聊天对话中无声无息地帮你储备下丰厚的文化知识
