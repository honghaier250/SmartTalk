# 键盘顶部操作栏开发指南

## 1. 概述

键盘顶部操作栏（CandidatesBar）是语言输入法键盘的重要组成部分，主要负责显示候选词和提供各种功能入口。本文档详细介绍其实现原理、代码结构和交互逻辑，以便开发者进行二次开发和功能扩展。

## 3. 视图结构

CandidatesBar包含两个主要视图，这些视图及其组件都定义在`CandidatesBar.kt`文件中：

1. **mCandidatesMenuContainer**：控制菜单视图，包含以下组件：
   - mIvMenuSetting：左侧设置按钮
   - mLlContainer：花漾字体类型容器
   - mRVContainerMenu：菜单项列表（RecyclerView）
   - mMenuRightArrowBtn：右侧箭头按钮
   - 这些组件在`initMenuView()`方法中进行初始化和配置

2. **mCandidatesDataContainer**：候选词视图，包含以下组件：
   - mRVCandidates：候选词列表（RecyclerView）
   - mRightArrowBtn：右侧箭头按钮（用于显示更多候选词或清空候选词）
   - 这些组件在`initCandidateView()`方法中进行初始化和配置

## 4. 初始化流程

1. **initialize(cvListener: CandidateViewListener)**：初始化CandidatesBar
   - 设置监听器
   - 计算菜单高度和内边距
   - 调用initMenuView()初始化菜单视图
   - 调用initCandidateView()初始化候选词视图

2. **initMenuView()**：初始化菜单视图
   - 创建并配置mCandidatesMenuContainer及其子视图
   - 设置菜单项点击监听器
   - 配置花漾字体类型选择器

3. **initCandidateView()**：初始化候选词视图
   - 创建并配置mCandidatesDataContainer及其子视图
   - 设置候选词列表适配器和点击监听器
   - 根据单手模式设置视图顺序

## 5. 交互逻辑

### 5.1 菜单项点击处理

当用户点击菜单项时，会触发以下流程：

1. CandidatesMenuAdapter中的点击监听器被调用
2. 获取点击位置对应的SkbMenuMode
3. 调用CandidatesBar.onClickMenu()方法
4. 根据SkbMenuMode执行相应操作或调用mCvListener.onClickMenu()

### 5.2 候选词点击处理

当用户点击候选词时，会触发以下流程：

1. CandidatesBarAdapter中的点击监听器被调用
2. 调用mCvListener.onClickChoice(position)方法

### 5.3 箭头按钮点击处理

- **mRightArrowBtn**：根据当前level执行不同操作
  - level为2：调用mCvListener.onClickClearCandidate()
  - 其他情况：调用mCvListener.onClickMore(level)并切换level

- **mMenuRightArrowBtn**：调用mCvListener.onClickMenu(SkbMenuMode.CloseSKB)

## 6. 视图切换

### 6.1 showCandidates()

显示候选词视图，根据当前容器类型和候选词状态决定显示内容：

- 如果当前容器是ClipBoardContainer，显示剪贴板相关菜单
- 如果候选词列表为空，显示菜单视图
- 否则显示候选词视图

### 6.2 showEmoji()

显示表情视图，加载表情相关菜单项。

### 6.3 showViewVisibility()

控制mCandidatesMenuContainer和mCandidatesDataContainer的可见性，实现视图切换。

## 7. 二次开发指南

### 7.1 添加新的功能入口

要在顶部操作栏添加新的功能入口，需要执行以下步骤：

1. 在SkbMenuMode.kt中添加新的枚举值
   ```kotlin
   enum class SkbMenuMode {
       // 现有枚举值...
       YourNewFunction,
       // 其他枚举值...
   }
   ```

2. 在menuSkbFunsPreset中添加新的菜单项定义
   - 这个预设列表定义在`d:\Project\Android\YuyanIme-master\yuyansdk\src\main\java\com\yuyan\imemodule\data\SkbFunData.kt`文件中，需要添加新的SkbFunItem
   - 示例：`menuSkbFunsPreset[SkbMenuMode.YourNewFunction] = SkbFunItem(SkbMenuMode.YourNewFunction, R.drawable.your_icon)`

3. 在CandidatesMenuAdapter中处理新功能的选中状态
   - 在`d:\Project\Android\YuyanIme-master\yuyansdk\src\main\java\com\yuyan\imemodule\adapter\CandidatesMenuAdapter.kt`文件的isSettingsMenuSelect()方法中添加新的case

4. 实现功能处理逻辑
   - 在实现CandidateViewListener接口的类`d:\Project\Android\YuyanIme-master\yuyansdk\src\main\java\com\yuyan\imemodule\view\keyboard\InputView.kt`中处理onClickMenu(SkbMenuMode.YourNewFunction)回调

### 7.2 修改现有功能

要修改现有功能，可以：

1. 修改CandidatesBar.kt中相应方法的实现
2. 更新布局文件以改变视觉效果
3. 修改适配器中的数据处理逻辑

### 7.3 自定义视图外观

要自定义视图外观，可以：

1. 修改布局文件（如sdk_item_recyclerview_candidates_menu.xml）
2. 在CandidatesBar.updateTheme()方法中添加自定义主题逻辑
3. 修改适配器中的视图绑定逻辑

## 8. 注意事项

1. CandidatesBar高度由EnvironmentSingleton.instance.heightForCandidates决定
2. 菜单项图标颜色根据主题和选中状态动态变化
3. 单手模式会影响候选词视图的布局顺序
4. 花漾字体功能可以通过CustomConstant.flowerTypeface控制
